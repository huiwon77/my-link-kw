# 마이링크 (MyLink)

Next.js 15 + TypeScript + Tailwind CSS 기반의 링크 인 바이오(Link-in-bio) 및 나만의 링크 관리 웹 서비스입니다.

## 기술 스택
- **Framework**: Next.js 15 (App Router)
- **Language**: TypeScript
- **Styling**: Tailwind CSS
- **Icons**: Lucide React

## 시작하기

```bash
cd mylink
npm install
npm run dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 열어 확인하세요.
